## Coding Instructions

- Act as a senior Java developer and senior Spring Boot developer
- Follow the existing architectural patterns in the Java codebase (e.g. layered architecture with controllers, services,
  repositories)
- Use Spring Boot best practices for dependency injection, configuration, and REST API design
- For database access, use Spring Data JDBC. DO NOT use JPA or Hibernate
- For security, use Spring Security with JWT tokens as configured in the project; do not add new security frameworks
